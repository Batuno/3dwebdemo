# Assets

Every third-party asset in `apps/showroom/public/assets/` is CC0 (public domain, no attribution required). Attribution is given here anyway, so the source of each file can be traced. Run `npm run assets` to re-download and re-compress everything from these sources (see `scripts/fetch-assets.mjs`).

## HDRI skies: Poly Haven, CC0

| File | Source asset | Link |
|---|---|---|
| `hdri/day.hdr`, `hdri/sky_day.webp` | Kloofendal 48d Partly Cloudy (Pure Sky) | https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky |
| `hdri/night.hdr`, `hdri/sky_night.webp` | Kloppenheim 02 (Pure Sky) | https://polyhaven.com/a/kloppenheim_02_puresky |

`.hdr` files are the 1K originals, used for image-based lighting. `sky_*.webp` are tone-compressed bakes of the 4K originals, used for a sharp background at a fraction of the size.

## Procedural (no external asset)

Generated from code at runtime, so there is nothing to license: towers and facades, trees and shrubs (leaf atlas above, bark from Bark014), cars, street lamps, playground, fitness equipment, shelter, court, pavilion, linkways, garage, neighbouring buildings, and the fitted furniture (sofa, beds, wardrobe, kitchen, bathroom fittings, TV, washer).
