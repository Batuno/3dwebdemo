# 3D Байр Сонголт

The project's notes. People write here in Obsidian, and every Claude Code session, in the cloud or on a computer, reads and writes the same notes.

- [[Now]]: current focus, open threads, next steps. Every Claude session reads it first.
- [[Overview]]: what the project is, where things live, links to the repository's own docs.
- [[How this vault works]]: opening it in Obsidian, how notes travel between Obsidian, the computers and the cloud.

## Folders

| Folder | What goes in it |
|---|---|
| `Inbox` | Anything you want Claude to see: requests, ideas, feedback, screenshots. New notes land here |
| `Sessions` | One note per Claude session: what was asked, done, decided and left open |
| `Decisions` | Choices made on purpose, so nobody undoes them by accident |
| `Ideas` | Things to do later |
| `Project` | Notes about the project itself |
| `Archive` | Inbox notes that have been dealt with |
| `Templates` | Starting points for new notes (Templates → Insert template) |
| `Attachments` | Images and files pasted into notes |

The latest sessions are linked from [[Now]]. Session notes are named by date, so sorting the `Sessions` folder by name shows them in order.
